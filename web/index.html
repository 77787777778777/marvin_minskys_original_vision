about

Every room, object, character, verb and even the unfolding ritual in this game is a Minsky frame (MIT AI Memo 306, A Framework for Representing Knowledge, 1974). The engine runs unmodified Tcl — the same adventure.tcl you can play in a terminal — inside the Feather WASM interpreter. When an action is impossible, the engine walks a difference network and may propose a whole plan (even across rooms); answer yes/no. NPCs plan with the same machinery, some over private, fallible beliefs. Ask the curator about almost anything for hints.
